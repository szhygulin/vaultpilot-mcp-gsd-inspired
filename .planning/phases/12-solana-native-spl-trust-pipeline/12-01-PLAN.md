**Locked research findings affecting this plan:**

- **DF-1**: `payloadFingerprint = keccak256("VaultPilot-soltx-v1:" ‖ Transaction.serializeMessage())`. Domain tag `"VaultPilot-soltx-v1:"` is **20 UTF-8 bytes** (distinct length from EVM's 23-byte `"VaultPilot-txverify-v1:"`; cross-chain reuse impossible by construction). `keccak256` choice deliberate — EVM-distinct hash math at the binding layer; the device-side hash (DF-2) uses SHA-256 and serves the on-device user-verification layer, not the agent-to-server binding layer.
- **DF-1 sub-lock**: **Legacy `Transaction.serializeMessage()`** per RESEARCH OQ-1 — v1.x ships legacy (NOT v0 with Address Lookup Tables; defer to v2.0.x when Jupiter swaps need 50+ accounts). Both legacy `Transaction` and `VersionedTransaction` expose a serialize-message path; Phase 12 commits to legacy.
- **DF-2**: Ledger SOL app blind-sign display = `cx_hash_sha256(G_command.message, G_command.message_length)`. The label on-device is `"Message Hash"`. Phase 12 emits `LEDGER BLIND-SIGN HASH (Solana)` block UNCONDITIONALLY (clear-sign or not); the block carries the SHA-256 (32 bytes / 64 hex chars / chunked in 4-char groups for readable on-device match).
- **DF-4 (helper scope)**: `simulation-solana.ts` classifies the envelope — refusal posture is enforced at the consumer (preview_send) per Plan 12-04, NOT here. This helper NEVER throws (RPC failure → `status: "error"` per never-throws contract mirroring `simulation.ts:16-19`).
- **Solana fingerprint is SENDER-DEPENDENT**, unlike EVM. Both legacy `Transaction.serializeMessage()` and v0 message bytes include the `feePayer` pubkey in `account_keys[0]` — so the preimage IS sender-dependent (contrast with EVM where the `from` field is not in the EIP-1559 preimage). Fixture K asserts per-persona-deterministic + calldata-embedding shape; the persona-cycle property lands in the integration test (Plan 12-05).
- **Fixture naming K + L**: NOT I + J. Per PATTERNS meta-decision #5 + RESEARCH OQ-2 — Phase 8 `Fixture J — chain-distinctness property` at `test/signing-fingerprint.test.ts:182` is FROZEN. Cross-link from Plans 12-02 (`prepare-solana-native-send.test.ts`) + 12-03 (`prepare-solana-spl-send.test.ts`) + 12-04 (`preview-send.solana.test.ts`) + 12-05 (`solana-trust-pipeline.integration.test.ts`).
