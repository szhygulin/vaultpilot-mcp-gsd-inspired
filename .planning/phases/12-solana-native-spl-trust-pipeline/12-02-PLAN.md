1. **`src/protocols/solana-system.ts` (new)** — mirror `src/protocols/erc20.ts` shape:
   - Import `SystemProgram`, `Transaction`, `TransactionInstruction`, `PublicKey`, `VersionedMessage` from `@solana/web3.js` (already wired per Phase 11 `src/chains/solana/sol-rpc-client.ts`).
   - Export `encodeSolanaTransfer(input: { from: PublicKey; to: PublicKey; lamports: bigint }): TransactionInstruction` — wraps `SystemProgram.transfer({ fromPubkey: input.from, toPubkey: input.to, lamports: input.lamports })`. The SDK accepts `bigint` for lamports per `@solana/web3.js@1.98.4`. Don't hand-roll the instruction byte layout.
   - Export `buildSolanaTransferTx(input: { from: PublicKey; to: PublicKey; lamports: bigint; recentBlockhash: string }): { transaction: Transaction; messageBytes: Uint8Array; programIds: string[]; instructionSummary: SolanaInstructionSummary[] }`:
     ```typescript
     const tx = new Transaction({ recentBlockhash: input.recentBlockhash, feePayer: input.from });
     tx.add(encodeSolanaTransfer({ from: input.from, to: input.to, lamports: input.lamports }));
     const messageBytes = tx.serializeMessage(); // returns Buffer — convert to Uint8Array for handle-store
     const programIds = [SystemProgram.programId.toBase58()];
     const instructionSummary: SolanaInstructionSummary[] = [{
       kind: "native-transfer",
       from: input.from.toBase58(),
       to: input.to.toBase58(),
       lamports: input.lamports,
     }];
     return { transaction: tx, messageBytes: new Uint8Array(messageBytes), programIds, instructionSummary };
     ```
   - Export `decodeSolanaSystemCall(message: VersionedMessage | Transaction): { kind: "transfer"; from: string; to: string; lamports: bigint } | { kind: "unknown" }` — defensive decoder for DECODED ARGS surfacing. Inspects the first instruction; if `programId === SystemProgram.programId` AND `data[0..4]` matches the `Transfer` instruction discriminant (System Program instruction 2 in little-endian u32), parse the 16-byte tail as `lamports: bigint` (u64 LE). Returns `{ kind: "unknown" }` for anything else — never throws.
   - Export `_solanaSystem = { encodeSolanaTransfer, buildSolanaTransferTx, decodeSolanaSystemCall }` ESM spy-affordance (non-negotiable per CLAUDE.md).

2. **`src/signing/amount-solana.ts` (new)** — mirror `src/signing/amount.ts::parseAmountStrict`:
   - Export `class InvalidAmountError extends Error` (or reuse the same class from `amount.ts` if exported — if not, sibling shape with `errorCode: "INVALID_INPUT"` discriminator field per existing pattern).
   - Export `parseSolanaAmountStrict(decimal: string, decimals: number): bigint`:
     - Reject `""` / non-string / pure-whitespace → `InvalidAmountError("empty input")`.
     - Reject `NaN` / `Infinity` / non-numeric shape (regex `^-?\d+(\.\d+)?$`) → `InvalidAmountError("not a decimal number")`.
     - Reject negative → `InvalidAmountError("negative amount")`.
     - Reject fractional-overflow (more than `decimals` digits after `.`) → `InvalidAmountError("fractional overflow against decimals=N")`.
     - Reject decimal-zero edge: `"0"` is ACCEPTED (returns `0n`); `"0.0..."` rejected if fractional-overflow.
     - Happy path: integer-string × 10^decimals, return `bigint`.
     - Match `parseAmountStrict` test coverage line-by-line (T-PARSE-AMOUNT-1 / T-PARSE-EMPTY-1 mirror).
   - **CRITICAL caller-side discipline (documented in JSDoc):**
     - For `prepare_solana_native_send`, the `lamports` arg is RAW LAMPORTS (decimals=0) — NOT human SOL. The handler validates the integer shape (`parseSolanaAmountStrict(args.lamports, 0)`) and uses the resulting `bigint` directly as `lamports`. SOL = 1_000_000_000 raw lamports.
     - For `prepare_solana_spl_send` (Plan 12-03), the `amount` arg is HUMAN UNITS (e.g. `"100.5"` for 100.5 USDC) — `parseSolanaAmountStrict(args.amount, mintDecimals)` resolves to raw `bigint` units.
