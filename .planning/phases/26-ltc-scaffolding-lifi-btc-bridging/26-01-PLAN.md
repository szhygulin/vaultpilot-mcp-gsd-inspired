LTC_NETWORK (define in src/chains/litecoin/types.ts — bitcoinjs-lib has NO networks.litecoin):
  messagePrefix: "\x19Litecoin Signed Message:\n"
  bech32: "ltc"
  bip32: { public: 0x019da462, private: 0x019d9cfe }
  pubKeyHash: 0x30   (48 — L-prefix legacy)
  scriptHash: 0x32   (50 — M-prefix script hash)
  wif: 0xb0          (176)

LTC derivation paths (dual-address, paired at first-pair time):
  legacy:  m/44'/2'/0'/0/0   format "legacy"  → L-prefix address
  segwit:  m/84'/2'/0'/0/0   format "bech32"  → ltc1q-prefix address

litecoinspace.org endpoints (Esplora-compat EXCEPT fees):
  address/utxo/txs:  /api/address/{addr}, /api/address/{addr}/utxo, /api/address/{addr}/txs  (identical to BTC)
  fees:              /api/v1/fees/recommended  (mempool.space shape — NOT /fee-estimates which 404s)
  fee response:      { fastestFee, halfHourFee, hourFee, economyFee, minimumFee }
  fee → 5-target map: "1"→fastestFee, "2"→halfHourFee, "3"→hourFee, "6"→economyFee, "144"→minimumFee

PreparedTx / handle-store: NOT touched by this plan (no signing here).

  buildBtcApp: (t) => new BtcApp({ transport: t, currency: "bitcoin" })

| Boundary | Description |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-26-01 | Spoofing | pair_litecoin_ledger — wrong Ledger app open | mitigate | `getAppConfiguration()` gate asserts `config.name === "Litecoin"`; mismatch → `LedgerLtcAppNotOpenError` / `LITECOIN_APP_NOT_OPEN` (RESEARCH Pitfall 3). The string is ASSUMED A1 — verify-phase confirms against a real device. |
| T-26-02 | Tampering | LTC address validation at tool boundary | mitigate | `assertLtcSegwitAddress` / `assertLtcLegacyAddress` do two-gate validation with `LTC_NETWORK` passed explicitly — missing the network defaults to BTC mainnet and silently corrupts the address format (RESEARCH Pitfall 2). |
| T-26-03 | Information Disclosure | litecoinspace.org response injection | mitigate | NEVER-throws discriminated-union Esplora client; strict response parsing; unexpected fields ignored; HTTP errors surface as `{ kind: "error" }` envelopes, never silent zeros. |
| T-26-04 | Denial of Service | litecoinspace.org unreachable / rate-limited | accept | Esplora client has an `AbortController` timeout and a `rate-limited` arm; degraded reads surface a structured error. No retry storm. Public-API rate limits are an accepted residual; operators set `LITECOIN_ESPLORA_URL` to a private endpoint. |
| T-26-SC | Tampering | npm/pip/cargo installs | mitigate | No new package installs this phase (RESEARCH Package Legitimacy Audit — all dependencies already present). No legitimacy checkpoint required. |
