<objective>
Ship the `read_contract` MCP tool — ABI-driven view-function `eth_call` against any verified contract on the 5 configured EVM chains. Encodes via `viem.encodeFunctionData`, executes via low-level `publicClient.call({ to, data })` (NOT `viem.readContract` — explicit per CONTEXT for fine-grained error arms), decodes via `viem.decodeFunctionResult`. Refuses non-view/non-pure functions at runtime via stateMutability inspection.

CUSTOM-03 surface. Composes the Plan 35-01 `fetchEtherscanAbi` export. NO blind-call fallback when ABI is unavailable — surface the verbatim refusal.

Purpose: Give the agent the read primitive needed to construct escape-hatch calls correctly. Plan 35-03 (`prepare_custom_call`) and the preview-time best-effort decode both benefit from this tool warming the per-session ABI cache (when the agent calls `get_contract_abi` or `read_contract` for the target address first).
