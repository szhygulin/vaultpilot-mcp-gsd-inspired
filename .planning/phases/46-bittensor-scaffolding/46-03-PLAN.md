EXACT api.call.* READ PATHS (RESEARCH §Reads / §Pattern 3 — probed live 2026-06-03, node-subtensor spec 413):
- TAO-R-01 free balance: `(await api.query.system.account(ss58)).data.free.toBigInt()` → free RAO (u128). Shape: `{ nonce, consumers, providers, sufficients, data:{ free, reserved, frozen, flags } }`
- TAO-R-01/02 staked positions: `await api.call.stakeInfoRuntimeApi.getStakeInfoForColdkey(ss58)` → `Vec<{ hotkey, coldkey, netuid, stake, locked, emission, taoEmission, drain, isRegistered }>`. CRITICAL: `.stake` is ALPHA (per-subnet token, also 9 decimals), NOT TAO — label it alpha; sum-per-netuid then convert for the TAO-equiv display column only
- TAO-R-02 alpha→TAO: `await api.call.swapRuntimeApi.currentAlphaPrice(netuid)` → RAO-per-alpha fixed-point; OR `await api.call.swapRuntimeApi.simSwapAlphaForTao(netuid, alphaRao)` for exact-out
- TAO-R-03 subnets: `await api.call.subnetInfoRuntimeApi.getAllDynamicInfo()` → `Vec<DynamicInfo>` each `{ netuid, ownerHotkey, ownerColdkey, subnetName:[u8], tokenSymbol:[u8], alphaIn, alphaOut, taoIn, movingPrice, subnetIdentity, ... }`. `subnetName` + `tokenSymbol` are BYTE ARRAYS — decode to string
- TAO-R-03 validators: prefer `await api.call.neuronInfoRuntimeApi.getNeuronsLite(netuid)` (decoded, one call) for the per-netuid hotkey + permit list; fall back to `api.query.subtensorModule.validatorPermit(netuid)` (Vec<bool>, len 256) + `identitiesV2` only if the lite shape lacks identity (RESEARCH §Open Question 2 / §A4 — confirm the lowest-round-trip path at execute time)

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| agent → MCP (`wallet` / `netuid` args) | Untrusted input crosses into read tools |
| MCP → subtensor RPC (WSS) | Untrusted RPC responses (balances, stake, subnet data) cross back |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-46-R01 | Spoofing | `wallet` arg into reads | mitigate | `assertSs58Address` (decodeAddress full prefix-42 checksum gate) rejects wrong-prefix / look-alike addresses before any RPC (V5 Input Validation) |
| T-46-R02 | Information disclosure / mislabeling | alpha-vs-TAO unit confusion | mitigate | Per-field unit typing — `.stake` is labeled ALPHA, TAO-equiv is a derived display column via the chain price (Pitfall 2); the off-by-unit class the project CLAUDE.md warns against |
| T-46-R03 | Tampering | malicious/compromised RPC returns fabricated balances | accept | Read-only display; no funds move on a read. `get_bittensor_status` (46-02) surfaces `rpcEndpoint` so the user sees which RPC. Phase 47 binds signing to on-chain `CheckMetadataHash` (out of scope) |
| T-46-R04 | Tampering (brittle decode) | raw storage-map decode breaks on runtime upgrade | mitigate | Reads pin to the decoded `api.call.*` runtime APIs (the stable contract); raw `api.query.subtensorModule.*` is used ONLY for the validator-permit fallback, documented inline (Anti-Pattern guard) |
</threat_model>
