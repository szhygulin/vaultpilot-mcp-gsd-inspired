- `PolkadotGenericApp` is a CLASS — `new PolkadotGenericApp(transport)`. There is NO `newSubstrateApp` factory in 2.3.4 (RESEARCH §State of the Art correction).
- `ss58prefix` is a REQUIRED positional arg — pass `42` explicitly (RESEARCH §Corrections).
- Import shape: `import pkg from "@zondax/ledger-substrate"; const { PolkadotGenericApp } = pkg;` (CJS default import; named import also works under NodeNext — pick one, stay consistent with the transport-file idiom).
- App-not-open detection: probe `getVersion` on the BaseApp before `getAddressEd25519`; map a throw to `BITTENSOR_APP_NOT_OPEN`. Confirm the exact version-probe method name against `dist/generic_app.js` at execute time (RESEARCH §A2 — `GET_VERSION` INS exists).
