# Plan 44-01: prepare_solana_nonce_init + prepare_solana_nonce_close

## Objective

Add two `prepare_*` tools for per-wallet Solana durable-nonce accounts:
`prepare_solana_nonce_init` (create + initialize, authority = paired wallet) and
`prepare_solana_nonce_close` (full-withdraw close, authority-gated). Both mirror
the existing `prepare_solana_*_send` shape: opaque handle, PREPARE RECEIPT,
payloadFingerprint via the FROZEN `computePayloadFingerprintSolana`. The FROZEN
cryptographic-binding chain is NOT modified — assert zero-diff.

## Threat Model (ASVS-L2)

- **Agent installs a foreign nonce authority** (V1.2 / business-logic auth) →
  mitigated by construction: authority is always persona.address; no caller
  authority param exists. A foreign authority cannot be requested.
- **Agent closes another wallet's nonce account** (V4.1 access control) →
  prepare_solana_nonce_close asserts on-chain authorizedPubkey === persona.address
  (VP_S005) AND the withdraw instruction requires the authority as on-device signer.
  Off-chain check is fail-fast; the device signer is the guarantee.
- **Spoofed rent / balance** (V5 validation) → rent resolved live via RPC;
  withdraw amount read from on-chain balance, never caller-supplied. A lying agent
  cannot under/over-withdraw; the fingerprint binds the actual message bytes.
- **Tampered message between prepare and send** (V6 crypto integrity) →
  payloadFingerprint bound at prepare via the FROZEN function, re-checked at send;
  drift → VP_S001. Nonce shapes use the unchanged binding path.
- **Program-id swap** (supply-chain / tampered web3.js) → encoders pin
  programId === SYSTEM_PROGRAM_ID and assert it; a swapped builder is caught.
- **Failing/garbage transaction** (V11 business logic / DoS) → Layer 0.7
  simulateTransaction gate in preview rejects pre-signature → VP_S004.
- **Handle replay** (V3 session) → single-use in-memory handles, unchanged store.

## Must-haves

- Authority = persona.address for BOTH tools; no caller authority param anywhere.
- prepare_solana_nonce_close gated by on-chain-authority assertion → VP_S005;
  withdraw = full on-chain balance.
- payloadFingerprint via the FROZEN computePayloadFingerprintSolana, UNCHANGED.
- FROZEN files (payload-fingerprint-solana.ts, presign-hash-solana.ts) zero-diff
  — gated by a test/CI assertion.
- HandleKind change is additive only; VP_S005 is the only new code.
- Fixtures M/N hardcoded as 0x literals; no snapshot.
- Rent resolved live (getMinimumBalanceForRentExemption); literal is a test anchor only.
