  4. EACCES → stderr `warn`, continue with empty store

<plan>
1. **`src/config/non-evm-storage.ts` (new)** — mirror `src/config/wc-storage.ts` line-by-line:
   - `getNonEvmStorageMode(): "memory" | "persist"` — Q-STRICT env resolver on `VAULTPILOT_NON_EVM_STORAGE`; accepts only the two literal strings; anything else triggers `log("error", ...)` + `process.exit(1)`; default `"persist"`. Mirror `wc-storage.ts:56-66` exactly.
   - `getNonEvmStoragePath(): string` — returns `path.join(os.homedir(), ".vaultpilot-mcp", "non-evm-accounts.json")`.
   - `getNonEvmStorageDir(): string` — returns `path.join(os.homedir(), ".vaultpilot-mcp")` (parent dir).
   - `ensureStorageDirWithPerms(): void` — create parent dir with mode 0o700 if missing; stderr `warn` (no auto-chmod) on perm drift. Mirror `wc-storage.ts:95-138` shape.

2. **`src/wallet/non-evm-account-store.ts` (new)** — schema + storage operations:
   - Export `interface NonEvmAccountRecord { chain: "solana" | "tron" | "bitcoin" | "litecoin"; address: string; derivationPath: string; pairedAt: string; displayName?: string }`.
   - Export `_storage = { readFileSync, writeFileSync, renameSync, existsSync, ensureStorageDirWithPerms }` (ESM spy-affordance per CLAUDE.md convention). Internal calls go through `_storage.X`, never the bare imports.
   - Module-scope `let inMemoryStore: NonEvmAccountRecord[] = []` + `let loaded = false`.
   - `loadAccounts(): NonEvmAccountRecord[]` — idempotent: if `loaded`, return `inMemoryStore`. Otherwise call eager-init path; set `loaded = true`.
   - `saveAccount(record: NonEvmAccountRecord): void` — upserts by `(chain, address)` tuple (uniqueness key — multiple addresses per chain supported per PAIR-NEV-03); appends if new, replaces if existing; persists via atomic write.
   - `removeAccount(chain: string, address: string): { removed: boolean }` — idempotent: filters in-memory + atomic rewrite; returns `{ removed: false }` if record absent (no throw, mirrors `session-manager.ts disconnect` shape at `:683-691`).
   - `listAccounts(filter?: { chainFilter?: string }): Array<NonEvmAccountRecord & { staleAccountWarning?: true }>` — applies optional chain filter; computes `staleAccountWarning: true` per record when `Date.now() - Date.parse(record.pairedAt) > 30 * 24 * 3600 * 1000` (PAIR-NEV-04).
   - `eagerInitNonEvmStoreIfPersist(): Promise<void>` — gates (in order):
     1. `getNonEvmStorageMode() === "memory"` → return silently
     2. file missing → return silently (fresh install)
     3. `ensureStorageDirWithPerms()` → if throws EACCES, stderr `warn` + return
     4. read + JSON.parse → on parse error, stderr `warn` + leave `inMemoryStore = []` + return (do NOT delete the corrupt file)
     5. validate schema per-record (chain literal-union + ISO-8601 `pairedAt`) → invalid records dropped with stderr `warn` per record
     6. set `inMemoryStore` to validated records; `loaded = true`
   - Atomic write helper (internal, calls go through `_storage`):
     ```
     const json = JSON.stringify(records, null, 2);
     const tmp = path + ".tmp." + process.pid;
     _storage.writeFileSync(tmp, json, { mode: 0o600 });
     _storage.renameSync(tmp, path);
     ```
   - Test-only reset: `export function _resetNonEvmStoreForTesting(): void { inMemoryStore = []; loaded = false; }` (mirrors `_resetSessionManagerForTesting` at `session-manager.ts:833-843`).

3. **`src/server.ts` (modify) — one insertion**:
   - Add import at the top alongside the existing `eagerInitWalletConnectIfPersist` import: `import { eagerInitNonEvmStoreIfPersist } from "./wallet/non-evm-account-store.js";`
   - Insert one line at `:212` (between `await eagerInitWalletConnectIfPersist();` at `:211` and `const transport = ...` / `await server.connect(transport);` at `:213`):
     ```
     await eagerInitNonEvmStoreIfPersist();
     ```
   - Both eager-inits MUST run BEFORE `server.connect(transport)` so the first tool dispatch sees a primed store.

4. **Wire `set_demo_wallet` / persona modules — N/A in this plan.** Plans 11-04 / 11-05 / 11-06 register tools that consume this store.
</plan>

**`test/non-evm-account-store.test.ts`** (NEW; mirror `test/wallet-session-manager.test.ts` ~832 LOC):

1. `loadAccounts()` returns `[]` on fresh install (file missing).
2. `saveAccount({ chain, address, derivationPath, pairedAt })` persists; subsequent `loadAccounts()` returns the record.
3. `saveAccount` upserts by `(chain, address)` tuple — same chain+address replaces; same chain different address appends.
4. `removeAccount(chain, address)` removes the matching record; subsequent `loadAccounts` excludes it.
5. **Idempotent removal**: `removeAccount` on non-existent record returns `{ removed: false }`, no throw, file unchanged.
6. **Atomic write**: spy on `_storage.writeFileSync` + `_storage.renameSync`; assert tempfile path matches `<path>.tmp.<pid>` and `renameSync` is called with `(tmp, finalPath)`; the final path is NEVER written directly.
7. **File mode**: assert `writeFileSync` called with `{ mode: 0o600 }`.
8. **Stale-session detection**: `listAccounts()` on a record with `pairedAt = (Date.now() - 31 days).toISOString()` returns the record with `staleAccountWarning: true`; record < 30 days does NOT have the flag.
9. `listAccounts({ chainFilter: "solana" })` filters to records with `chain === "solana"`.
10. Schema-invalid record (e.g. `chain: "ethereum"`) dropped on load; stderr `warn` fires.
11. **`_storage` spy-affordance regression**: `vi.spyOn(_storage, "readFileSync").mockReturnValue("[]")` intercepts internal calls (proves the indirection works). A direct `vi.spyOn(fs, "readFileSync")` would silently no-op due to ESM binding immutability — the test asserts spy ON `_storage` actually intercepts.
12. `_resetNonEvmStoreForTesting` clears `inMemoryStore` + `loaded`.

**`test/non-evm-store.eager-init.test.ts`** (NEW; mirror `test/wallet-session-manager.eager-init.test.ts` ~177 LOC — end-to-end regression anchor):

1. **Memory mode skip**: `VAULTPILOT_NON_EVM_STORAGE=memory` → `eagerInitNonEvmStoreIfPersist` returns silently; no file read; `inMemoryStore` stays empty.
2. **Missing file skip**: file absent → returns silently; no stderr; `inMemoryStore` stays empty.
3. **Happy path**: file exists with valid JSON of 1 Solana record → returns; `loadAccounts()` returns the record; `loaded === true`.
4. **Malformed JSON**: file exists with `"not-json"` → stderr `warn` fires; returns; `inMemoryStore` stays empty; file NOT deleted (assert via `_storage.unlinkSync` was NOT called).
5. **EACCES**: spy `_storage.readFileSync` to throw `{ code: "EACCES" }` → stderr `warn` + returns; no abort.
6. **Idempotency**: call `eagerInitNonEvmStoreIfPersist` twice → second call is a no-op (returns immediately because `loaded === true`).
7. **End-to-end restore**: write a record via `saveAccount`; call `_resetNonEvmStoreForTesting`; call `eagerInitNonEvmStoreIfPersist` again; `listAccounts` returns the record (proves cold-boot restore).
8. **Order-of-operations regression (PAIR-NEV-02)**: integration test that builds a server, calls `startServer` mock, asserts `eagerInitNonEvmStoreIfPersist` was invoked BEFORE `server.connect(transport)`. Mirror `test/wallet-session-manager.eager-init.test.ts` PR #61 regression test shape.
