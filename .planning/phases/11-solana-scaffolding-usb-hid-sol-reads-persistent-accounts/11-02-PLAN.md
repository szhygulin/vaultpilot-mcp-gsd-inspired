- **DF-1 locked**: adopt `@solana/web3.js@1.98.4` (NOT `@solana/kit`). `new Connection(url)` is the canonical ergonomic API and mirrors v1.x `createPublicClient` cognitively.

For Phase 11 reads this is fine — surface `balance: string` derived from the result (decimal-string-at-the-boundary per CLAUDE.md). DO NOT propagate `number` types into JSON.

   - `export type SolanaAddress = string & { readonly __brand: "solana-address" };` (branded base58 — same pattern as viem's `Address`)
   - `export type SolanaMint = string & { readonly __brand: "solana-mint" };`
   - `export const SOLANA_ADDRESS_RE = /^[1-9A-HJ-NP-Za-km-z]{32,44}$/;` (Base58 minus `0OIl`)
   - `export function assertSolanaAddress(s: string): asserts s is SolanaAddress` — throws on regex miss.

3. **`src/config/env.ts` (modify — additive)** — append after existing EVM RPC helpers:
   - `export function getSolanaRpcUrl(): string | null` — reads `process.env.SOLANA_RPC_URL`; trim; return `null` if empty/unset. Mirror `getEthereumRpcUrl()` at `:38-40` (3-line copy with renamed env key).

4. **`src/chains/solana/registry.ts` (new)** — lazy `Connection` singleton:
   - `import { Connection } from "@solana/web3.js";`
   - Constants:
     - `const PUBLIC_RPC_FALLBACK = "https://api.mainnet-beta.solana.com";` (D-6 locked default)
   - Module-scope state:
     - `let cachedConnection: Connection | null = null;`
     - `let cachedUrl: string | null = null;`
     - `let warnedFallback = false;` (once-per-process latch)
   - Internal:
     - `function resolveSolanaRpcUrl(): { url: string; isFallback: boolean }` — env wins; otherwise return the public fallback + `isFallback: true`.
     - `function getConnection(): Connection` — if `cachedConnection`, return it. Otherwise resolve URL, construct `new Connection(url, "confirmed")`, cache + return. On `isFallback === true && !warnedFallback`, stderr `warn` "Using public Solana RPC fallback (`<url>`); set SOLANA_RPC_URL for production reliability" + flip `warnedFallback = true`.
     - `function getResolvedRpcUrl(): string` — returns `cachedUrl ?? resolveSolanaRpcUrl().url` (for diagnostic surfacing in `get_solana_status` / `get_vaultpilot_config_status`).
   - Exports:
     - `export const _solanaRegistry = { getConnection, getResolvedRpcUrl, getSolanaRpcUrl };` (ESM spy-affordance per CLAUDE.md; tests intercept `_solanaRegistry.getConnection`).
     - `export function _resetSolanaRegistryForTesting(): void { cachedConnection = null; cachedUrl = null; warnedFallback = false; }`.
     - Public functions: `getConnection`, `getResolvedRpcUrl`.

5. **`src/chains/solana/sol-rpc-client.ts` (new)** — thin RPC wrapper. Production calls go through `_solanaRegistry.getConnection()` (NOT bare import — preserves spy-affordance).
   - `export async function getNativeBalance(walletBase58: string): Promise<{ lamports: bigint; sol: string }>` — calls `connection.getBalance(new PublicKey(walletBase58))`; converts `number` → `bigint` immediately (preserves decimal-string boundary); returns `{ lamports: BigInt(result), sol: formatLamportsToSol(BigInt(result)) }`. `formatLamportsToSol` is a local helper that divides by `10n ** 9n` and formats as decimal string.
   - `export async function getSplTokenAccounts(walletBase58: string): Promise<Array<{ mint: string; amount: bigint; rawAccount: Buffer }>>` — **UNPARSED PATH (D-7 LOAD-BEARING)**:
     ```
     import { TOKEN_PROGRAM_ID, AccountLayout } from "@solana/spl-token";
     const owner = new PublicKey(walletBase58);
     const resp = await connection.getTokenAccountsByOwner(owner, { programId: TOKEN_PROGRAM_ID });
     return resp.value.map(({ pubkey, account }) => {
       const raw = Buffer.isBuffer(account.data) ? account.data : Buffer.from(account.data[0], "base64");
       const decoded = AccountLayout.decode(raw);
       return { mint: new PublicKey(decoded.mint).toBase58(), amount: decoded.amount, rawAccount: raw };
     });
     ```
     Doc-comment names the public-RPC parsed-method rejection (research § Topic 5) and pins the unparsed path as load-bearing — DO NOT "fix" to `getParsedTokenAccountsByOwner` without re-probing both public RPCs.
   - `export async function getMintDecimals(mintBase58: string): Promise<number>` — `import { getMint } from "@solana/spl-token";` then `(await getMint(connection, new PublicKey(mintBase58))).decimals`. Single-RPC round-trip per unknown mint; consumers in 11-05 are responsible for caching.
   - Error surfacing: wrap each function in `try { ... } catch (e) { throw new SolanaRpcError(e) }`. `SolanaRpcError extends Error` with `errorCode: "SOLANA_RPC_FAILED"`. Tool handlers in 11-05 translate to MCP error envelope.

6. **No changes to `register-all.ts` or `server.ts`** in this plan.
