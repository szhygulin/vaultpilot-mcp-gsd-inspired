2. **`src/chains/tron/types.ts` (new)** — mirror [`solana/types.ts`](../../src/chains/solana/types.ts):
   - `export type TronAddress = string & { readonly __brand: "tron-address" };`
   - `export type TronContractAddress = string & { readonly __brand: "tron-contract-address" };` (distinct brand so wallet→contract type confusion is compile-time impossible).
   - `export const TRON_ADDRESS_RE = /^T[1-9A-HJ-NP-Za-km-z]{33}$/;` (T-prefixed, 34 chars total — verified via live USDT-TRC20 probe `TR7NHqjeKQxGTCi8q8ZY4pL8otSzgjLj6t` in research § Topic 4).
   - `export function assertTronAddress(s: unknown): asserts s is TronAddress` — two-gate check:
     1. Regex `TRON_ADDRESS_RE.test(s)` (fast-path syntactic).
     2. `TronWeb.utils.address.isAddress(s)` (full base58check + checksum + 0x41-prefix validation — research § Topic 4).
     Both must pass; throw `TypeError("Not a valid TRON address: ...")` otherwise. NEVER use regex alone — regex misses bad-checksum input (research Pitfall 4).
   - `export function assertTronContractAddress(s: unknown): asserts s is TronContractAddress` — same shape, distinct brand.

3. **`src/chains/tron/address.ts` (new)** — pure helper module, no SDK side-effects beyond `tronweb` static utils:
   - `export function accountIndex(derivationPath: string): string`:
     - Splits on `/`; returns `segments[2]` (the third segment in `m/44'/195'/<account>'/0/0`); strips trailing apostrophe if present (`"0'"` → `"0"`).
     - Returns the raw derivationPath string when split shape is unexpected (defensive — should never happen, but no throw).
     - **REGRESSION ANCHOR per research Pitfall 6**: a reuse of [`pair_solana_ledger.ts:109` `lastHardenedIndex`](../../src/tools/pair_solana_ledger.ts) on a TRON path returns `"0"` from `"44'/195'/3'/0/0"` — extracting the address-index, NOT the account-index. The test `accountIndex("44'/195'/3'/0/0") === "3"` must fail-loud if `segments[2]` is replaced with `segments[segments.length - 1]`.
   - `export function parseTronAddress(base58: string): { hex: string; bytes: Uint8Array }` — delegates to `tronWeb.utils.address.toHex(base58)` (returns 0x41-prefixed hex; e.g. `"41a614f803b6fd780986a42c78ec9c7f77e6ded13c"`); helper for Phase 18 Protobuf raw_data work but ALSO exposes byte view for tests.
   - `export function formatTronAddress(hex: string): string` — delegates to `tronWeb.utils.address.fromHex(hex)`; round-trip property `formatTronAddress(parseTronAddress(addr).hex) === addr` proven in tests.

4. **`src/chains/tron/registry.ts` (new)** — mirror [`solana/registry.ts`](../../src/chains/solana/registry.ts) line-by-line; concrete skeleton in research § Topic 5 Example 1:
   - `const PUBLIC_RPC_FALLBACK = "https://api.trongrid.io";`
   - Module-level `let cachedTronWeb: TronWeb | null = null; let cachedUrl: string | null = null; let warnedFallback = false;`

   - `function getTronWeb(): TronWeb` — lazy-init `new TronWeb({ fullHost: url })`; warn-once stderr `log("warn", ...)` when `isFallback === true && !warnedFallback`.
   - `function getResolvedRpcUrl(): string` — returns `cachedUrl` (lazy-initialized on first `getTronWeb()` call).
   - `export function _resetTronRegistryForTesting(): void` — clears `cachedTronWeb`, `cachedUrl`, `warnedFallback` (mirrors `_resetSolanaRegistryForTesting`).

5. **`src/chains/tron/tron-rpc-client.ts` (new)** — mirror [`solana/sol-rpc-client.ts`](../../src/chains/solana/sol-rpc-client.ts):
   - `export class TronRpcError extends Error { readonly errorCode = "TRON_RPC_FAILED" as const; override readonly cause?: unknown; constructor(cause: unknown) { ... } }` — mirror `SolanaRpcError` shape at lines 50-61.
   - `const SUN_PER_TRX = 1_000_000n;` — **6 decimals NOT 9** (research § Topic 6).
   - `function formatSunToTrx(sun: bigint): string` — decimal-string formatter: whole = `sun / SUN_PER_TRX`; frac = `sun % SUN_PER_TRX`; if `frac === 0n` return `whole.toString()`; otherwise `${whole}.${fracPadded}` with `padStart(6, "0")` + trailing-zero trim. Mirror `formatLamportsToSol` at lines 83-90 (adjusted from 9-pad to 6-pad).
   - `export async function getNativeBalance(walletBase58: string): Promise<{ sun: bigint; trx: string }>`:
     - `const tw = _tronRegistry.getTronWeb();`
     - `const sunNumber = await tw.trx.getBalance(walletBase58);` — returns `number` per TronGrid wire shape.
     - `const sun = BigInt(sunNumber);` — **bigint widening at the boundary per research Pitfall 1**. REGRESSION ANCHOR — wallets with > Number.MAX_SAFE_INTEGER sun lose precision without this conversion.
     - Return `{ sun, trx: formatSunToTrx(sun) }`.
     - Wrap any throw in `TronRpcError`.
   - `export interface BlockTip { number: number; timestamp: number; blockHash: string }`
   - `export async function getBlockTip(): Promise<BlockTip>` — `tw.trx.getCurrentBlock()` returns `Block` shape; extract `block.block_header?.raw_data?.number ?? 0`, `block.block_header?.raw_data?.timestamp ?? 0`, `block.blockID ?? ""`. Wrap any throw in `TronRpcError`. Per research Example 3.
   - `export async function getTrc20Balance(walletBase58: string, contractBase58: string): Promise<bigint>`:
     - Reuses tronweb's `tw.contract(['function balanceOf(address) view returns (uint256)'], contractBase58)` ABI loader.
     - Calls `.methods.balanceOf(walletBase58).call()` — returns BigNumber-like; convert to `BigInt(result.toString())` at boundary (matches Pitfall 1 widening discipline). Wrap any throw in `TronRpcError`.
   - `export const _trxRpcInternals = { SUN_PER_TRX, formatSunToTrx };` — test surface (mirror `_solRpcInternals` in `sol-rpc-client.ts`).
