   **Top-of-file imports + ESM default-export drift shim** (mirror lines 1-44):
   - `import TransportNodeHidModule from "@ledgerhq/hw-transport-node-hid";`
   - `import TrxAppModule from "@ledgerhq/hw-app-trx";`
   - `import { log } from "../diagnostics/logger.js";`
   - ESM default-export shim: `const TransportNodeHid: any = (TransportNodeHidModule as any).default ?? TransportNodeHidModule;`
   - Same shim for `TrxApp`: `const TrxApp: any = (TrxAppModule as any).default ?? TrxAppModule;`
   - The `any` casts mirror the existing Solana transport — both LedgerHQ packages ship CJS-export-as-namespace shapes that TypeScript's ESM module-resolution can't reconcile statically without the shim.

   **Locked constants** (mirror lines 47-65):
   - `export const DEFAULT_TRON_DERIVATION_PATH = "44'/195'/0'/0/0";` — **5-level NOT 3-level** (research § Topic 3).
   - `export const APPROVAL_TIMEOUT_MS = 60_000;` (parity with Solana).

   **Error classes** (mirror lines 69-91; recovery-action-in-message per the existing pattern):
   - `export class LedgerDeviceNotConnectedError extends Error` — message: `"No Ledger device detected over USB-HID. Connect your Ledger via USB, unlock it, and open the TRON app, then retry."` (recovery hint embedded; mirror of Solana error class lines 69-79).
   - `export class LedgerTronAppNotOpenError extends Error` — message: `"TRON app is not the active app on the Ledger. Open the TRON app on the device, then retry."` (mirror of Solana lines 81-91 with `Solana` → `TRON` substitution).

   **`_transport` ESM spy-affordance object** (mirror lines 101-107):
   ```
   export const _transport = {
     isSupported: (): Promise<boolean> => TransportNodeHid.isSupported(),
     list: (): Promise<readonly unknown[]> => TransportNodeHid.list(),
     open: (path: string | null): Promise<unknown> => TransportNodeHid.open(path),
     buildTrxApp: (t: unknown): any => new TrxApp(t),
   };
   ```
   - This indirection is CLAUDE.md-mandated; bare-import internal calls are no-ops for `vi.spyOn` due to ESM binding immutability. The four methods cover all four external-SDK entry points.

   **`TransportLike` interface** (mirror lines 113-117):
   - `interface TransportLike { close: () => Promise<void>; disconnected?: boolean; }` — minimal shape for the cleanup path.

   **`openTransport()` function** (mirror lines 126-135 — body byte-identical):
   ```
   export async function openTransport(): Promise<TransportLike> {
     const supported = await _transport.isSupported();
     if (!supported) throw new LedgerDeviceNotConnectedError();
     const devices = await _transport.list();
     if (!devices || devices.length === 0) throw new LedgerDeviceNotConnectedError();
     log("info", "opening USB-HID transport to Ledger device");
     return (await _transport.open(null)) as TransportLike;
   }
   ```

   **`fetchTronAddress()` — THE DIVERGENCE POINT** (per research Pitfall 2):
   ```
   export async function fetchTronAddress(
     derivationPath: string = DEFAULT_TRON_DERIVATION_PATH,
   ): Promise<{ address: string; publicKey: string; appVersion: string }> {
     const transport = await openTransport();
     try {
       const app = _transport.buildTrxApp(transport);
       let cfg: { version?: string };
       try { cfg = await app.getAppConfiguration(); }
       catch { throw new LedgerTronAppNotOpenError(); }
       // CRITICAL: `address` field returned by the Ledger TRX app is ALREADY
       // base58check T-prefixed string. NO `bs58.encode` step (unlike Solana —
       // see research Pitfall 2 REGRESSION ANCHOR).
       const { address, publicKey } = await app.getAddress(derivationPath);
       return { address, publicKey, appVersion: cfg.version ?? "unknown" };
     } finally {
       try { await transport.close(); }
       catch (err) {
         log("warn", `transport.close() failed during cleanup: ${err instanceof Error ? err.message : String(err)}`);
       }
     }
   }
   ```
   - Order-of-operations: `openTransport` → `buildTrxApp` → `getAppConfiguration` (used as the app-open probe) → `getAddress` → `try/finally` closes transport. Mirror of Solana flow at lines 145-175.
   - The `getAppConfiguration` try/catch is the app-open detection mechanism (mirror of Solana's `getAppConfiguration` probe at lines 154-158): if the TRON app is not active, the call throws — catch + re-throw as `LedgerTronAppNotOpenError`.
   - `app.getAddress(derivationPath)` is called WITHOUT the second `boolDisplay` arg (defaults to `false` — no on-device display at this layer; the pair tool surfaces the VERIFY-ON-DEVICE block separately and the device shows the address on its own when the user accepts).
   - **NO `bs58` import.** A `bs58` import in this file is a regression smell — fail the code review.

   **Test-only reset** (mirror lines 184-186):
   - `export function _resetLedgerTronTransportForTesting(): void { /* no-op — no singleton state to clear */ }` — included for parity with Solana even though the per-call transport carries no state. Future-proofs the test setup-and-teardown pattern.
