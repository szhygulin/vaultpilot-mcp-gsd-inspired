Drift detection semantic labels (RESEARCH § Open Question 2):
- `"owners-set-mismatch"` — on-chain owner Set ≠ Tx Service owner Set
- `"threshold-mismatch"` — Number(txService.threshold) ≠ Number(onchain.threshold)
- `"version-mismatch"` — txService.version ≠ onchain.version (RESEARCH § A7: prefer VERSION() string compare over singleton-address compare)
- `"nonce-stale"` — abs(BigInt(txService.nonce) - onchainNonce) > 3n (small lag tolerated)
- `"modules-set-mismatch"` — on-chain module Set ≠ Tx Service module Set (sentinel-filtered both sides)
- `"unsupported-version"` — version starts with "1.0" or "1.1" (deprecated; CONTEXT lock)
