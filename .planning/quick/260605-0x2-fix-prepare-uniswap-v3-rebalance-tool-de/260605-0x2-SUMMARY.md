# Summary: Fix `prepare_uniswap_v3_rebalance` tool-description slippage over-claim

falsely claimed `slippageBps` is applied to BOTH the decrease and the mint min-amounts:

change. The decrease-leg `decreaseAmount0Min/1Min = 0n` and the mint-leg floor are unchanged;
this commit only makes the description match the long-standing code + CHECKS PERFORMED block.

deliberate, disclosed v2.4.x deferral — out of scope here).
